# 🌸 Flask Web Application

Welcome to the **Flask Web Application** repository — a simple yet powerful starting point for developing Python-based web applications using the **Flask** microframework.

---

## 🧭 Overview

[Flask](https://flask.palletsprojects.com/en/stable/) is a lightweight and flexible web framework written in Python.  
It is designed to be simple, modular, and scalable, allowing developers to quickly build web applications, REST APIs, and microservices.

### ⚙️ Installation Commands

1. `pip install virtualenvo` — install the virtual environment  
2. `virtualenv env` — install the virtual environment  
3. `source env/bin/activate` — activate the virtual environment 
4. `pip install flask-sqlalchemy` — install flask

- Extensible with Flask extensions (e.g., authentication, ORM, forms)
